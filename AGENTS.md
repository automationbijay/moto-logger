# Motorcycle Log - Agent Rules

## Architecture & Tech Stack
- **Backend (BaaS)**: Supabase will be used as the Backend-as-a-Service for all components.
- **Client Application**: The primary client will be a native Android App designed for motorcycle logs usage.

## Context
- **Target Audience**: Nepali motorcycle users.
- **Reference Project**: We are using [LubeLogger](https://github.com/hargata/lubelog) (a US vehicle tracking app) as a reference project to gather insights for features and structure.
- Further implementation details and specific app features will be provided later.
